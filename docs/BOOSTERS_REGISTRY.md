# MBSD: Boosters & Automation Registry

**Directive:** Boredom, file operations, heavy log parsing, and generic C-scaffolding must be delegated to automated boosters. The Principal Architect (Gemini) strictly handles kernel-level logic and MT7981 math.

## 1. Local Antigravity Swarm (Primary Brains)
- **Subagent Swarm (Gemini 3.1 Pro):** Recursive autonomous agents spawned via `invoke_subagent`. 
  - *Current Active Booster:* `Kernel_Forge` (Locked in infinite cross-compilation loop).
- **Research Drones (Gemini Flash):** Cheap, fast models for reading dense MediaTek PDF datasheets and stripping garbage.

## 2. Local CLI Accelerators (The Grunts)
- **GitHub Copilot CLI (`gh copilot`):** Used via bash scripts to instantly generate generic boilerplate (Makefile structures, standard OpenBSD struct definitions) without burning premium context tokens.
- **Ollama (Local LLMs):** If installed on macOS or "WD", used via bash pipes (`cat build.log | ollama run llama3 "extract fatal error"`) to parse infinite `make` logs for free.

## 3. IDE Automation (Trae Work)
- **Trae Background Tasks:** Guided strictly by the `ASSASSINS_CREED.md` rules. When Trae is unblocked (via limits/billing), it serves as the file-manipulation workhorse.

## Execution Policy
Whenever a task is classified as "Boredom" (e.g., parsing 10,000 lines of OpenWrt Linux code to find one register offset), a Booster script is written to execute it.
